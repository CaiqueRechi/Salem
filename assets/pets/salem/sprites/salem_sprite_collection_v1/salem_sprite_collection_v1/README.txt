SALEM SPRITE COLLECTION v1

All exported PNG sprites are exactly 64x64 px, RGBA, transparent.
full_sheet_64x64.png packs them in 64x64 cells, 8 columns.

Folders:
reference, idle, walk, sit, sleep, eat, play, stretch, curious,
interaction, objects, events, zoomies, moods.

Important:
- These files were extracted from the generated master atlas and normalized
  without regenerating individual poses.
- The generated atlas visually duplicated the final bed cell; 55_bed_02 uses
  that same source cell as a fallback.
- Review pixel cleanup/alignment in Pixelorama before production use.
